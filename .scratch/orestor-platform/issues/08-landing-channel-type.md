# 08: Landing-page channel type

**What to build:** The wizard and the channel dashboard support a landing channel: one main product chosen from the catalogue, a landing template (banner, product, gallery, benefits, price, order form, FAQ, reassurance), and orders through the same queue as stores. Multi-product screens (categories, catalogue management) are hidden for this type. Replacing the main product requires an explicit selection. When the main product becomes unavailable, the channel applies the configured rule: hide the order form, show unavailable, or suspend publication.
